# Conversor de Temperatura

Projeto desenvolvido com HTML, CSS e JavaScript para conversão de temperaturas entre Celsius, Fahrenheit e Kelvin, utilizando interface moderna e manipulação dinâmica do DOM.

## Objetivo

Praticar conceitos fundamentais de desenvolvimento front-end, incluindo formulários, eventos, lógica matemática, manipulação do DOM e estilização moderna com CSS.

## Funcionalidades

- Conversão entre Celsius, Fahrenheit e Kelvin
- Atualização dinâmica dos resultados
- Exibição das fórmulas utilizadas
- Interface moderna responsiva
- Campos de entrada e seleção de escala

## Conversões realizadas

- Celsius → Fahrenheit / Kelvin
- Fahrenheit → Celsius / Kelvin
- Kelvin → Celsius / Fahrenheit

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Conceitos praticados

- Manipulação do DOM
- Eventos com JavaScript
- Estruturas condicionais
- Conversão de dados numéricos
- Captura de dados de formulários
- Template strings
- Atualização dinâmica de elementos HTML
- Flexbox
- Gradientes e sombras modernas

## Observação
- Projeto desenvolvido para fins educacionais e prática de desenvolvimento front-end.
